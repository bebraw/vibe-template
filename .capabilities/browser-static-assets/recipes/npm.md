# npm Recipe

This kit uses the target's TypeScript and Playwright toolchain. Reconcile existing versions before installing anything; do not add a second compiler or browser-test stack.

If either tool is absent, install the exact versions after approval:

```bash
npm install --save-dev --save-exact typescript@npm:@typescript/typescript6@6.0.2 typescript-7@npm:typescript@7.0.2 @playwright/test@1.62.1
```

## Package Scripts

Merge these scripts into `package.json`:

```json
{
  "scripts": {
    "build:browser": "node ./node_modules/typescript-7/bin/tsc --project tsconfig.browser.json",
    "watch:browser": "node ./node_modules/typescript-7/bin/tsc --project tsconfig.browser.json --watch --preserveWatchOutput"
  }
}
```

`watch:browser` is available for standalone use. Wrangler's custom build uses the same one-shot compiler and watches `src/browser/` while `wrangler dev` is running.

## Wrangler Configuration

Merge these fields into the existing `wrangler.jsonc`:

```jsonc
{
  "assets": {
    "directory": "./public",
    "html_handling": "none",
    "not_found_handling": "none",
    "run_worker_first": ["/*", "!/assets/*"],
  },
  "build": {
    "command": "npm run build:browser",
    "watch_dir": ["src/browser", "tsconfig.browser.json"],
  },
}
```

The route pattern sends application requests through the Worker and lets `/assets/*` use the static-assets path. Adjust it if the target already serves other public files or requires Worker middleware for assets. Do not add an `ASSETS` binding unless Worker code needs to fetch assets directly.

Wrangler runs the custom command for local development and direct CLI deployments. Workers Builds does not honor Wrangler custom builds, so configure `npm run build:browser` as the dashboard build command when that service owns deployments.

## Files And HTML

Copy or merge:

- `files/tsconfig.browser.json` to `tsconfig.browser.json`
- `files/src/browser/browser-entry.ts` to `src/browser/browser-entry.ts`
- `files/src/browser-entry.e2e.ts` to `src/browser-entry.e2e.ts`
- `files/public/_headers` to `public/_headers`

Add `public/assets/` to `.gitignore`; it is generated by `build:browser`. Keep authored public assets and `_headers` tracked.

Add this external module to the Worker-rendered document. A module script is deferred by default:

```html
<script type="module" src="/assets/browser-entry.js"></script>
```

Do not add inline fallback code. The server-rendered page remains the core path when the module is unavailable.
